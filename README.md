# 🏃‍♂️ Análise de Tráfego Pago & Previsão de Faturamento (E-commerce de Corrida)

Projeto prático de ciência de dados focado no tratamento de dados de campanhas publicitárias, análise de vendas por categoria e construção de um modelo preditivo de faturamento usando Regressão Linear.

## 📌 Objetivos
- **Limpeza de Dados**: Padronização de categorias de produtos, eliminação de duplicidades e tratamento de valores ausentes (imputação pela mediana).
- **Análise Exploratória**: Identificação dos segmentos de maior receita (*Tênis de Placa* e *Relógios GPS*).
- **Modelagem Preditiva**: Modelagem da relação entre investimento em anúncios (*Ads*) e faturamento da loja.

## 🛠️ Tecnologias Utilizadas
- **Linguagem**: Python
- **Manipulação de Dados**: Pandas
- **Machine Learning**: Scikit-Learn
- **Visualização**: Matplotlib

## 📈 Resultados do Modelo
- **Coeficiente Angular**: ~3,83 (Cada R$ 1.000 aplicados em Ads geram um aumento estimado de R$ 3.825,75 no faturamento).
- **Simulação de Cenário**: Investimento de R$ 50k prevê faturamento de ~R$ 186,55k.
